# Security reports

Report Django-specific security issues to this repository's maintainer. Use
GitHub private vulnerability reporting when available. Share only sanitized
reproduction details; keep credentials, pairing keys, captured media and private
messages out of public issues.

The upstream Visor policy is preserved for attribution under
[docs/upstream/SECURITY.md](docs/upstream/SECURITY.md). Django-specific reports
should not be sent to upstream maintainers by default.
